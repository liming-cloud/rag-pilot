# 工程北极星

目标：**AI 写的改动一次就对；出错由机器当场发现；人只做决定。**

## 指标

两个仓库（rag-pilot、domain-forge）口径一致，目标值由人定。

| 指标 | 口径 |
| --- | --- |
| 规则可执行率 | 带自动检查的规则卡 ÷ 全部规则卡（基线见[规则卡索引](../rules/00-索引.md)） |
| 快速反馈 | 本地快速门禁和 CI 完整门禁的时长 |
| 一次通过率 | 没打 `rework` 的 PR ÷ 全部 PR |
| 逃逸缺陷 | 带 `escaped-defect` 标签的 Issue 数 |
| 编译告警 | 为 0，由编译参数 `-Werror` 门禁保证（#199） |

## 实践规范

后续优化 Issue 以这些规范为依据；括号里是本仓库里的参照代码。

### A 一致性

- A1 充血聚合，构造器就是不变量（`Conversation`）。
- A2 会被并发修改的聚合带版本号，条件更新影响 0 行时报冲突；后台任务只做窄更新（`MybatisConversationRepository`）。
- A3 模型调用、外部 IO 不放进数据库事务（`ChunkWriter`）。
- A4 清缓存、删文件、触发后台任务在提交后执行（`JsonCaches`、`DocumentRemover`）。
- A5 一个事务只改一个聚合，例外写理由；GET 不写库。

### B 错误与日志

- B1 只有一个异常基类，由唯一出口转成 HTTP，领域违规直接带错误码。
- B2 通用异常不逃出 application。
- B3 包装异常保留 cause；降级至少记 warn。
- B4 日志只用占位符，格式为 `event=snake_case 键=值`，不记敏感内容。

### C 类型与编译

- C1 全包 `@NullMarked`。
- C2 编译用 `-Xlint:all -Werror`。
- C3 圈复杂度 ≤10、方法语句 ≤30，由机器检查；行数只作参考。

### D 简洁

- D1 同一个形状只有一个类型。
- D2 重复三次以上的样板抽成工具。
- D3 端口和适配器是防腐层，不算“只转发的层”，但适配器里不复制样板。

### E 测试

- E1 断言结果；越权场景断言没有返回、没有写入。
- E2 应用层分支用简单实现快速测，集成测试只验证真实数据库和并发。
- E3 集成测试共享容器、Spring 上下文能复用；不 sleep；断言用强类型。
- E4 测试替身只写一份。
- E5 接口契约由机器校验，覆盖读接口、写接口和 SSE。

### F 流程

- F1 AGENTS.md 只做路由。
- F2 写短 ADR（[决策索引](../decisions/README.md)）。
- F3 每条规则要么由机器检查，要么写明“评审”（规则卡的“检查”字段）。
- F4 Issue 驱动。
- F5 过程守卫交给机器（`guard`、hook）。
- F6 度量标签 `rework`、`escaped-defect`。

决定见 [D-066](../decisions/D-066-统一Issue和PR约定.md)、[D-067](../decisions/D-067-工程优化的范围与答复.md)。
