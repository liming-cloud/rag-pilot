# D-059 未决问题答复：#168 拆分后的 #180～#183（2026-11-07）

#168 拆成 #180（工具调用通路）、#181（数据范围授权）、#182（问答编排与引用）、#183（工具评测）。人对四个 Issue 的未决问题**全部按推荐**答复：

- **#180**：令牌签名私钥只从环境变量读（如 `RAG_TOOL_SIGNING_KEY`），不进库、不进日志、不做管理端轮换；客户 MCP 端点（URL、受众、JWKS）先用 `@ConfigurationProperties` 配置，不存库、不做管理页；模拟服务放在 rag-app 的测试源码里用内嵌 HTTP 服务，不新增 Maven 模块，评测需要时再提成 Testcontainers 镜像。
- **#181**：门店、区域主数据由客户 MCP 服务的只读工具提供（如 `list_stores`），授权页读取并缓存，不另建门店表；用户授权与角色授权同时存在时取**并集**（权限语义，与知识库授权一致）；区域授权按调用时的门店主数据展开，新增门店自动在范围内。

- **#183**：指标口径——工具选择正确率 = 该调且调对工具的题数 / 该调工具的题数，参数正确率单列，越权调用 = 范围外调用实际发出的次数（目标 0），目标值 ≥ 80% 沿用 D-056；题量约 60（越权至少 20）；进 PR 自动跑的 `eval`，加入后需确认超时。
