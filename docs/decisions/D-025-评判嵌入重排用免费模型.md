# D-025 评判和嵌入、重排用免费模型，回答保留 DeepSeek-V3（2026-10-28，默认评判模型已被 D-026 取代）

试点阶段尽量用硅基流动的免费模型。嵌入 `BAAI/bge-m3`、重排 `BAAI/bge-reranker-v2-m3` 本来免费；评测的默认评判模型由 `Qwen/Qwen2.5-72B-Instruct`（收费）改为免费的 `Qwen/Qwen2.5-7B-Instruct`，与回答模型不同系列，避免自评偏高（D-026 又改为 `THUDM/GLM-4-9B-0414`）。7B 评判更容易判错，开源数据集结果先人工抽查再用来校准门槛。

回答模型试过免费模型，合成集 47 题误拒率：DeepSeek-V3 2.7%（首字 p95 3.3 秒）、GLM-4-9B-0414 32.4%、Qwen2.5-7B-Instruct 37.8%（多数是回答不带 [n] 引用或自称答不了）、Xing4.0-29B 10.8% 但首字 p95 16 秒。差距太大，回答（含低分改写）保留收费的 `deepseek-ai/DeepSeek-V3`，全量开源评测一次约 5 元（估算）。`eval`、`eval-public` 可以手动输入回答模型做对比。免费额度容易限流，嵌入调用改为遇到 429 和服务端错误时退避重试 3 次（入库在后台进行，不阻塞请求）。
