# D-042 产品默认名称“明答”，名称和登录页文案由部署配置（2026-10-30）

#117 经人答复：默认名称和登录页内容交由 AI 规划，其余采纳建议。内核默认名称用“明答”（回答明明白白、有据可查）：两个字、读起来顺，不带行业属性，以后加上 AI 大脑也不用改名。原定的“知枢”经人评审读起来拗口，从“明答、有据、知答、慧答”里由人选定“明答”；新零售试点在部署配置里设成“门店运营知识库”。登录页 PC 端左右分栏：左侧品牌区放名称、slogan、一张体现核心价值的插图（带引用编号的回答连着原文资料、授权盾牌、“找不到就直说”）和三条核心价值（答案有出处可核对、按授权作答不越权、答不了就直说），右侧登录卡片；窄屏退化为居中卡片。默认 slogan“每个回答，都有出处”，登录按钮下方默认提示“账号由管理员开通；忘记密码请联系管理员。”。名称、slogan、提示这一步用环境变量配置、重启生效，M5 做系统设置页时改为管理员在界面里修改（环境变量作默认值）；不做 Logo 上传；问答页的占位和空状态提示随 M5 的行业包文案一起做。三条核心价值是内核的产品主张，不随行业变，写在前端。
