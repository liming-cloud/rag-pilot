# D-043 模型管理第一步的范围：四个用途、多服务商、密钥加密存库（2026-11-01）

#120 经人答复，全部采纳建议：

- **用途**：界面上能配回答、备用（首字慢时的备用请求，D-028）、轻量任务（会话标题，D-036）、重排四个；低分改写和追问检索词跟随回答的模型。嵌入只显示不能改（换嵌入要重建索引，1.x）；评判只在评测里用，不进界面。回答的温度、最大字数、超时、备用等待时间等参数仍在配置文件，界面只配模型名。
- **服务商**：可以同时有多个，每个用途选“服务商 + 模型名”；这一步只支持 OpenAI 兼容接口，重排走兼容的 `/rerank`。
- **密钥**：用 JDK 自带的 AES-GCM 加密存库，主密钥是环境变量 `RAG_MASTER_KEY`（32 字节随机值），不新增依赖；接口和日志都不返回明文，界面只显示后 4 位。没设主密钥时不能在界面保存密钥。主密钥丢失只能重新录入密钥，这一步不做轮换。AGENTS.md 的密钥约束随之修改。
- **来源**：某个用途在界面保存过就以数据库为准，没保存过就用环境变量，界面标出每个用途当前的来源。
- **连通测试**：保存前对该用途发一句极短的请求（重排送一对短文本），超时 10 秒，不通过不能保存；恢复变更记录时同样先测。
- **验收评测**：在界面把回答模型配成与环境变量相同的模型，合成集三轮与 M3 持平（误拒 2.3%、越权 0、其余 100%）；换成别的模型时评测只作记录。
- **权限**：`model:view`、`model:test`、`model:update` 默认只有超级管理员。
