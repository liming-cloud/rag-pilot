# D-027 允许部分回答，开源集拒答正确率低于 90% 可接受（2026-10-29）

#68 把回答提示词的“资料不足就只回 NO_ANSWER”改成：资料只能回答一部分时，先答能答的部分并标注出处，再说明哪部分资料里没有提到；问题要求结合、比较时，可以对照、归纳各条资料里的事实，但不补充资料外的事实；只有资料与问题完全无关才回 NO_ANSWER。

同一批 200 道开源题（GLM-4-9B 评判）对比：误拒从 5.0%（8 题）降到 2.5%（4 题），双文档题从 12.5% 降到 7.5%；拒答正确率从 92.5% 降到 87.5%，低于 README 的 90% 目标。多出的 2 道“应拒答却回答了”都是只答资料里有的部分、标了出处，并明确说明缺什么，没有编造。合成集（门店场景）拒答正确率仍是 100%。对员工来说，“能答的部分加上缺什么”比只说找不到更有用，经人工决定接受这个取舍。

以后看开源集的拒答正确率要逐题看“应拒答却回答了”的题：一类是合理的部分回答；另一类是转换脚本只按事件文字排除，同一件事的其他报道还留在语料里（30 题复核时发现），回答其实有依据。两类都不算编造。门店场景仍以合成集和私有评测集的拒答正确率 ≥ 90% 为准；越权泄漏仍必须为 0。
