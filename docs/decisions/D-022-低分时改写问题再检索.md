# D-022 低分时改写问题再检索（2026-10-28）

#46 的两次真实模型评测显示，改写、口语、错字题召回 100%，但重排对这类问法打分偏低（0.002–0.146），低于门槛被误拒。对策是只在重排最高分低于门槛、本来要拒答时，用对话模型把问题改写成规范说法再检索、重排一次；正常问题不受影响。改写器实现 Spring AI 的 `QueryTransformer`，但不用框架的 `RewriteQueryTransformer`，因为它直接建 `ChatClient`，绕开 rag-ai；提示词只写通用规则，不针对评测题。开关 `rag.answering.rewrite-on-low-relevance`（评测里是 `EVAL_REWRITE`），代价是本来要拒答的问题多等一次模型调用，评测报告单列改写耗时和“应拒答题被改写后回答了”的题数。
