# D-038 按钮级 RBAC、超级管理员与账号安全的规则（2026-10-30）

#115 经人工决定：现有账号迁移时，最早创建的 ADMIN（初始化的管理员）成为超级管理员，其余 ADMIN 成为“管理员”，STAFF 成为“员工”，现有的逐人授权原样保留。内置“管理员”默认有知识库、用户、回答记录、使用统计的全部权限；“角色与权限”“模型管理”“系统设置”默认只给超级管理员。防止越权分配：给别人分配的角色，权限点不能超出自己拥有的；只有超级管理员能分配含“角色与权限”的角色；不能停用、重置权限不少于自己的账号。

同一账号连续 5 次密码错误锁 15 分钟，管理员可手动解锁，不按 IP 锁。密码 8–64 位、不强制复杂度、不能与用户名相同；管理员重置后员工下次登录必须先改密码。超级管理员密码丢失时，运维设置 `RAG_ADMIN_RESET_PASSWORD` 后重启重置，日志提示删掉该变量，不提供网页找回。还有用户的角色和内置角色不能删。没有权限的菜单和按钮直接隐藏，不置灰。
