# D-040 标准分页组件；问答页的知识库选择收进一个按钮（2026-10-30）

#115 第二次原型评审：分页改为完整的标准分页——共几条、每页条数（10/20/50/100，改了回到第 1 页）、上一页、页码（首末页和当前页前后，断开处用省略号）、下一页、跳至某页（超出范围跳到最后一页），所有管理列表共用 `components/ui/pagination`。问答页顶部原来把已授权的库逐个铺成标签，库一多就占掉对话区；改为一个按钮，写“全部知识库（N）”、库名或“某库 等 N 个”，点开在弹窗里搜索、全选、勾选，点“确定”才改会话的选择，至少选一个；收回授权的库在按钮旁提示“N 个库已无权限”，弹窗里不能勾选。用已有的 Dialog，不新增依赖。
