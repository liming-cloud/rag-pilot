# D-032 拒答门槛 0.2、改写下限 0.03 保持不变，有数据依据（2026-10-29）

#81 让评测能连续跑多轮，并按每题的重排最高分推算不同门槛的效果（`EvalRounds`）。合成集 3 轮（[run 40860903009](https://github.com/liming-cloud/rag-pilot/actions/runs/40860903009)，47 题）：误拒每轮都是 2.7%，拒答、引用正确率 100%；门槛在 0.10–0.20 之间指标不变，0.30 时误拒升到 8.1%，低于 0.10 拒答正确率开始下降。开源集一轮（[run 40892144507](https://github.com/liming-cloud/rag-pilot/actions/runs/40892144507)，500 题）：门槛从 0.20 降到 0.10，拒答正确率 81.0% → 73.0%，误拒只少 0.3 个百分点；升到 0.50，拒答正确率不变，误拒从 3.3% 升到 4.0%。0.2 两边都在最优位置，作为校准后的值，不再是占位值（D-014）。

改写下限：合成集每轮改写 4 题、救回 3 题，低于下限跳过的 10 题里唯一的可回答题是“鲜食下架-口语”（0.002，见下）；开源集改写 20 题、救回 0 题，低于下限跳过的可回答题 2 道（0.006、0.022），改写更高分的题都救不回，它们也救不回来。下限保持 0.03。

开源集拒答正确率 81%（100 道应拒答题答了 19 道）：19 道的重排最高分都在 0.9 以上，17 道是完整回答、2 道是部分回答，属于 D-027 说的转换脚本只按事件文字排除、同一事件的其他报道仍在语料里，回答有依据，不是编造。按 D-027，门店场景以合成集和私有评测集为准；清洗开源集应拒答题记入 ROADMAP 待办。

“鲜食下架-口语”（“便当饭团晚上几点得撤下来啊”）3 轮都因低分拒答：资料只写“鲜食”，要知道便当、饭团属于鲜食才能检索到，是行业词汇问题，不靠调门槛解决。接受这一题失败，M5 的行业包加入行业词表，用这题验收。
