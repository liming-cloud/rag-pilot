# 规则卡索引

规则正文只写在规则卡里，其他文档链接过来。AGENTS.md 是路由，工程北极星见 [北极星](../engineering/北极星.md)，决策见 [决策索引](../decisions/README.md)。

## 卡片格式

每张卡是所在文件里的一个二级标题 `## X-nn 标题`，卡号全仓库唯一，下面四行：

- `规则：` 要做什么或不能做什么；
- `理由：` 为什么，必要时链接决策（D-nnn）；
- `状态：` 生效 / 已取代（写明新卡号）；
- `检查：` 三种之一：`自动[测试名]`（由测试或脚本检查，可加括号备注哪些部分靠评审）、`测试`（有测试覆盖行为但不是规则检查）、`评审`（靠人评审）。

`DocLinksTest` 检查：链接与锚点、卡号唯一、引用的卡号和决策编号存在、本索引覆盖全部卡、检查方式合法、`自动[…]` 里的测试能找到。

## 规则可执行率

自动检查的卡 ÷ 全部卡 = 27 ÷ 56（基线，#196 合并时）。新增或修改卡时同步更新本数字和 README。
